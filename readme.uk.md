Інтеграція для **Home Assistant**, що показує наявність електропостачання у вашій області та черзі.

Це **нова версія (v2.8.6)**, яка дозволяє змінювати налаштування через інтерфейс (UI) з опцією збереження старих entities IDs, підтримує майже всі регіони через єдиний надійний API та автоматично очищує старі сутності.

---

## ⚙️ Основні можливості

- ✅ Показує **поточний статус** світла (`Є / Немає`),  
- ✅ Визначає **наступне вмикання** та **відключення** електроенергії,  
- ✅ Показує час **останнього оновлення розкладу**,  
- ✅ **Єдиний надійний API**: Використовує спеціалізований проксі, що агрегує дані з DTEK/YASNO та інших офіційних джерел для максимальної точності.
- ✅ **Налаштування через UI**: Змінюйте чергу, підчергу або інтервал оновлення "на льоту" без перевстановлення.
- ✅ **Розумне очищення**: Автоматично видаляє старі сутності та пристрої при зміні налаштувань.
- ✅ Має **вбудовану локалізацію** (UA / EN),  
- ✅ Планує **точне перемикання сутностей** у момент зміни графіка — без додаткових запитів до API.

## 🔄 Принцип роботи

### 🧩 Архітектура інтеграції
1. **Єдиний координатор:** Усі черги/регіони використовують спільне кешоване джерело даних, щоб мінімізувати запити.
2. **Розумне кешування:** Дані оновлюються кожні 10 хвилин за замовчуванням (налаштовується для кожного запису: 8–60 хвилин). Якщо у вас налаштовано кілька черг, вони використовують один завантажений JSON.
3. **Точний таймер:** Інтеграція розраховує час наступного перемикання і планує внутрішній таймер. Якщо світло вимкнено до 18:00, сенсор перемкнеться на "Ввімкнено" рівно о 18:00:00, не чекаючи наступного опитування API.

### 🕒 Таймзона
- API повертає розклад у **локальному українському часі (Europe/Kyiv)**.  
- Інтеграція коректно конвертує цей час у UTC для Home Assistant, тому все відображається точно незалежно від часового поясу сервера.

## 🔐 Конфіденційність та Безпека

Інтеграція **не містить і не передає ключі API**.

Доступ до даних здійснюється через захищений **Cloudflare Worker**, який:
- Агрегує дані безпосередньо з офіційних сайтів постачальників.
- Повертає стандартизований JSON.
- Не потребує жодних приватних даних від користувача.

## ⚙️ Налаштування та використання

### Встановлення через HACS
Найшвидший шлях — через [HACS](https://github.com/hacs/integration):
1. Відкрийте HACS → Інтеграції.
2. Знайдіть `Svitlo.live` (або додайте цей репозиторій як custom repository).
3. Натисніть **Завантажити**.
4. Перезапустіть Home Assistant.

### Додавання інтеграції
1. Перейдіть у **Налаштування → Пристрої та служби → Додати інтеграцію**.
2. Знайдіть **Svitlo.live**.
3. Оберіть вашу **Область** та **Чергу**.

### Зміна черги (Нове у v2.8.0)
Більше не потрібно видаляти інтеграцію, щоб змінити чергу!
1. Перейдіть на картку інтеграції в Home Assistant.
2. Натисніть **Налаштувати** (значок шестерні ⚙️).
3. Оберіть нову чергу/підчергу зі списку.
4. (Опціонально) Змініть **Інтервал оновлення** (стандартно: 900 с / 15 хв).
5. Натисніть **Надіслати**.  
   *Інтеграція перезавантажиться, видалить старі сутності та створить нові автоматично.*

## 🧩 Створювані сутності (Entities)

| Тип | Назва | Опис |
|-----|-------|------|
| 🟢 **Binary Sensor** | `Electricity status` | Бінарний статус (є світло / немає) |
| 📘 **Sensor** | `Electricity` | Текстовий статус: “Grid ON / OFF” |
| ⏰ **Sensor** | `Next grid connection` | Час ввімкнення (якщо зараз вимкнено) |
| ⚠️ **Sensor** | `Next outage` | Час вимкнення (якщо зараз ввімкнено) |
| 🔄 **Sensor** | `Schedule updated` | Час останнього успішного оновлення даних |
| 📅 **Calendar** | `calendar.svitlo_<region>_<queue>` | Події “💡 Electricity available” (Київський час) |
| ⏳ **Sensor** | `Minutes to grid connection` | Хвилин до появи світла (зворотний відлік) |
| ⏱ **Sensor** | `Minutes to outage` | Хвилин до відключення (зворотний відлік) |

## 🤖 Blueprints (Автоматизації)

Разом з інтеграцією автоматично встановлюються blueprints для сповіщень про зміну графіку.
1. Перейдіть в **Налаштування → Автоматизації та сцени**.
2. Натисніть **Створити автоматизацію → Почати з blueprint**.
3. Виберіть **"Svitlo Live: ..."**.
4. Заповніть поля.
